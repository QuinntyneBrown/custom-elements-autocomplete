# Custom Elements Autocomplete

Native Web Components with open Shadow DOM, lit-html rendering, and RxJS input handling.
Product searches debounce input for 200 ms and cancel superseded requests. Select a result to
expand its category, volume, price, and tasting notes.

Start with **Concepts → Developer → Quick Start**, then explore the component API tables.
All examples use local fixtures and require no API credentials. The toolbar switches scoped
component themes and text direction while this documentation stays light.
